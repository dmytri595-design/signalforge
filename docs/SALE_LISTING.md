**Product:** SignalForge — Webhook Reliability Lab

**Short pitch:** Break the webhook happy path before production does.

**Description:** SignalForge is a zero-setup, browser-local reliability workbench for teams building webhook consumers. Create event fixtures, configure simulated receiver profiles, exercise flaky 503s, 429 rate limits, 500s, timeouts and invalid signatures, inspect retry timelines, test HMAC-SHA256 signatures, model duplicate-delivery/idempotency behavior, and compare nested JSON payload versions for potentially breaking contract drift. Persist experiment history and export JSON, CSV and Markdown reports. It runs without API keys, external services, a build step or runtime network calls.

**Problem solved:** Webhook retry, duplicate-delivery, signature and payload-contract edge cases are easy to miss in happy-path tests and expensive to reproduce after release. SignalForge provides a repeatable local lab for those failure modes.
