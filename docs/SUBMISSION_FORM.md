## Description
SignalForge is a zero-setup, browser-local webhook reliability workbench for developers and QA teams. It lets users inspect event fixtures, simulate flaky 503 responses, 429 rate limits, persistent 500s, timeouts and invalid signatures, review retry timelines, test HMAC-SHA256 signing and tamper detection, model duplicate-delivery/idempotency strategies, and compare nested JSON payloads for potentially breaking contract drift. Workspace history persists locally, with JSON backup/restore and CSV/Markdown exports. It runs as a static app without API keys, external services, a build step, or runtime network calls.

## Problem Solved
Webhook integrations often fail in edge cases that happy-path tests miss: retries, duplicate deliveries, signature mismatches, timestamp tolerance and payload changes. Reproducing these cases usually requires custom scripts, staging infrastructure or waiting for production failures. SignalForge packages those scenarios into a repeatable local developer lab.
